# Loja de Camisas de Futebol

Projeto desenvolvido durante o **1º semestre de TSI**, utilizando apenas **HTML e CSS**.

O objetivo do projeto foi criar uma loja virtual de camisas de futebol, aplicando os conhecimentos aprendidos durante as aulas de desenvolvimento web.

## Tecnologias utilizadas

* HTML5
* CSS3

## Sobre o projeto

O site simula uma loja virtual de camisas de futebol e possui diferentes páginas e seções, incluindo:

* Página inicial
* Categorias de produtos
* Página de login
* Página de cadastro
* Página de contato
* Página "Sobre"

As páginas foram desenvolvidas apenas com HTML e CSS, sem utilização de JavaScript ou back-end.

## Estrutura do projeto

```text
projeto/
├── CSS/
├── Categoria/
├── Imagens/
├── cadastro.html
├── contato.html
├── index.html
├── login.html
└── sobre.html
```

## Objetivo

O projeto foi desenvolvido para praticar conceitos aprendidos durante o primeiro semestre, como:

* Estruturação de páginas utilizando HTML
* HTML semântico
* Estilização com CSS
* Flexbox
* Organização de layouts
* Formulários
* Navegação entre páginas
* Organização de arquivos e pastas
